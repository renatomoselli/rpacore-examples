# Support

RPA Core Examples supports the public examples, their documentation, and the
documented workflow for installing a compatible RPA Core release.

## Supported Scope

- Reproducible bugs in committed examples.
- Documentation problems in this repository.
- Example dependency and setup issues.
- Compatibility notes between examples and the documented RPA Core release.

## Out of Scope

- Framework internals, packaging, and public API design, which belong in the
  `rpacore` repository.
- Private user automations derived from these examples.
- Third-party websites, desktop applications, browser drivers, credentials,
  local network services, or optional libraries outside the example contract.
- A cloud service SLA or guaranteed response time.

## Where To Ask

Use GitHub issues for reproducible example bugs, documentation problems, and
example requests. Use the security route in [SECURITY.md](SECURITY.md) for
vulnerability reports.
