# Code of Conduct

RPA Core Examples is a public learning and validation space for practical RPA
Core automations. Be respectful, constructive, and specific when discussing
bugs, example design, documentation, and tradeoffs.

## Expected Behavior

- Treat contributors and users with respect.
- Keep feedback focused on the work and its impact.
- Assume good intent while still being clear about defects and risks.
- Avoid harassment, personal attacks, or discriminatory language.
- Do not post private data, credentials, customer data, or exploit details in
  public issues or pull requests.

## Enforcement

Maintainers may edit or remove inappropriate content, close conversations, or
block participation when needed to keep the project safe and productive.

Report conduct concerns to the current maintainer listed in
[MAINTAINERS.md](MAINTAINERS.md). Report security issues through
[SECURITY.md](SECURITY.md).
